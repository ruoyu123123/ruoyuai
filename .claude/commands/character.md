你是一位专业的角色塑造专家。请帮我创建/完善以下角色：

$ARGUMENTS

请提供完整的角色档案，包括：
1. 基本信息（姓名、年龄、外貌、职业等）
2. 性格特征和心理特质
3. 背景故事和成长经历
4. 核心动机和目标
5. 优点、缺点和矛盾点
6. 人际关系网络
7. 角色成长弧线建议
8. 独特的说话方式和行为习惯
9. **情境触发语 Barks**（v16 新增 · 移植自游戏NPC Bark系统）

## Bark 系统说明

每个角色在人物卡中新增 `barks` 字段——按情境分类的短句库：

```json
"barks": {
  "combat": ["操！", "闪开！", "别挡路。"],
  "tension": ["……不对劲。", "后退。"],
  "daily": ["行吧。", "吃了吗？"],
  "discovery": ["等一下。", "你看这个。"],
  "emotional": ["……算了。", "嗯。"]
}
```

**writer agent 写作时：** 场景匹配情境→优先从barks中选句→用voice_pack风格化→自然嵌入对话。这让角色的即兴反应更真实，不是每次都现编。

要求：角色要立体、有深度，避免扁平化和刻板印象。

## 人物弧光三层架构（v16 新增 · 基于编剧方法论+认知心理学）

**每个重要角色必须回答3个问题：**

| 层 | 问题 | 说明 | 示例 |
|---|---|---|---|
| 谎言 | 角色坚信什么错误观念？ | 来自过去创伤/失败/扭曲教育 | "独自扛着不求人才是坚强" |
| 欲望线 | 角色的外在目标是什么？ | 必须和谎言产生冲突 | "查清父亲失踪的真相" |
| 需求线 | 角色真正需要学会什么？ | 经历弧光后信奉的真理 | "信任别人不是软弱" |

**弧光公式：** 谎言（开始）→ 欲望驱动行动 → 遭遇挫折（谎言受到挑战）→ 觉醒（发现需求/真理）→ 新行动（基于真理而非谎言）

**硬币式人物设计：**
- 正面（社会面）：职业身份+能力+社会角色
- 背面（烟火气）：私人习惯+小缺陷+日常偏好
- 每次出场至少展示一面+偶尔翻转

**对立工具人设计：**
- 纵容角色谎言的人（让角色更深陷错误）
- 引导角色走向真理的人（导师/挚友/对手）
- 两者冲突→角色被迫选择→弧光实现
