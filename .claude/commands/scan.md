# 扫榜/市场分析（v16 新增 · 对齐 oh-story 扫榜功能）

## 用法

```
/scan 都市悬疑          — 搜索该题材的热门作品
/scan 起点 玄幻月票榜   — 搜索特定平台的排行榜
/scan 对标 《作品名》   — 分析特定作品的卖点
```

## 执行流程

1. 用 WebSearch 搜索目标题材的热门作品（起点/番茄/知乎等平台）
2. 提取 TOP 5-10 作品的核心信息
3. 分析共同卖点和差异化方向

## 输出格式

```
📊 市场扫描：<题材>

══ 热门作品 TOP 5 ══
┌──────────┬────────┬──────────┬──────────────┐
│ 作品     │ 平台   │ 收藏/追读│ 核心卖点     │
├──────────┼────────┼──────────┼──────────────┤
│ ...      │ ...    │ ...      │ ...          │
└──────────┴────────┴──────────┴──────────────┘

══ 共同卖点 ══
- 卖点1：...
- 卖点2：...

══ 差异化机会 ══
- 方向1：...
- 方向2：...

══ 节奏参考 ══
- 黄金三章策略：...
- 高潮频率：...
- 读者期待管理：...
```

## 注意事项

- 搜索结果仅供参考，不代表你必须照搬
- 重点关注"读者为什么追"而非"作者怎么写"
- 输出可直接作为 /brainstorm 和 /outline 的输入参考
