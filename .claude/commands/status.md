# 工作流状态面板（v16 新增 · 移植自 novelgen_win 的 panel.py）

## 扫描内容

用 Read/Glob 检查以下状态：

### 1. 项目基本信息
- 读取 `_数据库/进度.json`：总章数/已完成/当前/字数目标
- 读取 `_数据库/项目配置.json`（如有）：模板/激活系统
- 检查风格文件：`_数据库/作者风格.json` 和 `_数据库/作者风格_skill.md` 是否存在

### 2. 章节状态
- Glob `第*章*.txt`：列出已生成的章节文件
- 检查最新章节是否有 `---CHANGES---` 段（已完成 vs 草稿）
- 检查 `_数据库/章纲摘要.json`：摘要数 vs 章节文件数（不匹配=save-state未完成）

### 3. 数据库完整性
- 检查13个必须JSON是否都存在
- 检查 `.manifest/` 下是否有当前章的manifest
- 检查 `.wal/` 下是否有未关闭的WAL（save-state中断信号）
- 检查 `.audit/` 下最近一次审计结果

### 4. 待处理事项
- 读取 `进度.json` 的 `propagation_debt`：有几条pending
- 读取 `伏笔表.json`：有几条Tier-1即将到期
- 检查 `voiceprint_tracking.json`：声纹追踪是否正常

### 5. Git状态
- 检查是否有未提交的改动
- 最近一次commit信息

## 下一步建议逻辑

| 状态 | 建议 |
|---|---|
| WAL未关闭 | `/continue` 恢复中断的save-state |
| 摘要不同步 | `/save-state <N>` 补完状态保存 |
| 传播负债≥5 | `/reconcile` 清偿传播负债 |
| 伏笔Tier-1即将到期 | 提醒下一章必须回收 |
| 一切正常 | `/write-chapter <N+1>` 继续写作 |
| 无项目 | `/write` 开始新项目 |
