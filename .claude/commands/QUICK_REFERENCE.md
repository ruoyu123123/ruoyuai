# 快速参考卡 - 小说创作命令

## 🚀 一分钟上手

```
1. /write 关键词 或 "我想写XX题材"
   👉 选/蒸馏风格 → AI 生成灵感 → 你选

2. /outline 我选第X个
   👉 卷级大势 + 初始化 34 子系统 + 详化 cluster_001

3. /cluster-write
   👉 写一个故事块（writer 自由发挥 → 双轨质检 → splitter 按字数切）

4. /cluster-save-state
   👉 状态保存 + 涌现下个故事块 → 走向卡（你选）→ 回到第 3 步
```

---

## 📋 命令速查表

| 命令 | 用途 | 输入 | 输出 |
|------|------|------|------|
| `/write` | 端到端引导（含灵感生成） | 题材/关键词 | 灵感卡 → 全流程 |
| `/outline` | 生成大纲 | 故事描述 | 卷级大势 + 34 子系统 |
| `/cluster-write` | 写一个故事块 | cluster_id | 故事块草稿 → 切章 |
| `/cluster-save-state` | 状态保存 + 涌现 | cluster_id | 摘要账本 + 走向卡 |
| `/continue` | 续写/断点恢复 | 前文/进度 | 接续写作 |
| `/check-quality` | 质量检查 | 章节内容 | 评分+改进建议 |

---

## ✅ 质量检查清单（写完立即自查）

- [ ] 开头100字是否抓人？
- [ ] 是否有旁白式概括？（❌禁止）
- [ ] 对话是否口语化？
- [ ] 环境描写是否超过3句？（❌禁止）
- [ ] 是否有总结性结尾？（❌禁止）
- [ ] 情节是否推进了？
- [ ] 人物行为是否符合逻辑？

---

## 🎯 核心原则（背下来！）

1. **痛点前置**：第一句话就要扎心
2. **具体替代抽象**：用动作代替情绪
3. **对话推剧情**：每句话都有用
4. **克制即高级**：少写环境和心理
5. **场景收尾**：结尾用画面，不总结

---

## 🔥 常见错误对照表

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "他感到很愤怒" | "他把杯子摔在地上" |
| "表面看起来平静，但内心..." | 删掉，用对话和动作展现 |
| "从今晚起，你已踏入一个隐秘世界" | "以后小心点，别乱说话" |
| "窗外月光如水，洒在院子里..." | "月亮很亮" 或直接删掉 |
| "那一刻，他明白了人生的真谛" | 用具体行动展现领悟 |

## 📊 字数参考

- **短篇小说**：10-15章，每章2,500-3,500字 = 2.5-5万字
- **中篇小说**：20-30章，每章3,000-4,000字 = 6-12万字
- **长篇小说**：50+章，每章3,000-5,000字 = 15万字+

---

## 💡 黄金建议

1. **写作前**：大纲越详细，写作越快
2. **写作中**：每500字问自己"读者会继续看吗？"
3. **写作后**：朗读一遍，检查对话是否自然
4. **发布前**：用 `/check-quality` 最后检查一遍

## 🆘 紧急救援

**卡文了怎么办？**
```
/continue [已写内容] + "请提供3个可能的发展方向"
```

**写偏了怎么办？**
```
/check-quality [内容]
→ 查看问题 → 针对性修改
```

**不知道下一章写什么？**
```
回头看大纲的"伏笔时间表"
→ 找到该回收的伏笔
→ 围绕伏笔设计情节
```

2. **具体的画面 > 抽象的描述**
3. **不要证明，只要创造**
