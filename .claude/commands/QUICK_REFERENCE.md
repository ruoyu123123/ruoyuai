# 快速参考卡 - 小说创作命令

## 🚀 一分钟上手

```
1. /brainstorm 关键词1, 关键词2, 关键词3
   👉 生成5个导语

2. /outline 我选第X个，[导语内容]
   👉 生成详细大纲

3. /write-chapter [第X章大纲]
   👉 写作章节（重复此步骤完成所有章节）

4. /check-quality [章节内容]
   👉 检查质量（可选）
```

---

## 📋 命令速查表

| 命令 | 用途 | 输入 | 输出 |
|------|------|------|------|
| `/brainstorm` | 生成导语 | 关键词 | 5个导语+梗概 |
| `/outline` | 生成大纲 | 故事描述 | 详细章节大纲 |
| `/write-chapter` | 写作章节 | 章节大纲 | 完整章节txt |
| `/continue` | 续写内容 | 前文/进度 | 续写800-1500字 |
| `/check-quality` | 质量检查 | 章节内容 | 评分+改进建议 |

---

## ✅ 质量检查清单（写完立即自查）

- [ ] 开头100字是否抓人？
- [ ] 是否有旁白式概括？（❌禁止）
- [ ] 对话是否口语化？
- [ ] 环境描写是否超过3句？（❌禁止）
- [ ] 是否有总结性结尾？（❌禁止）
- [ ] 情节是否推进了？
- [ ] 人物行为是否符合逻辑？

---

## 🎯 核心原则（背下来！）

1. **痛点前置**：第一句话就要扎心
2. **具体替代抽象**：用动作代替情绪
3. **对话推剧情**：每句话都有用
4. **克制即高级**：少写环境和心理
5. **场景收尾**：结尾用画面，不总结

---

## 🔥 常见错误对照表

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "他感到很愤怒" | "他把杯子摔在地上" |
| "表面看起来平静，但内心..." | 删掉，用对话和动作展现 |
| "从今晚起，你已踏入一个隐秘世界" | "以后小心点，别乱说话" |
| "窗外月光如水，洒在院子里..." | "月亮很亮" 或直接删掉 |
| "那一刻，他明白了人生的真谛" | 用具体行动展现领悟 |

## 📊 字数参考

- **短篇小说**：10-15章，每章2,500-3,500字 = 2.5-5万字
- **中篇小说**：20-30章，每章3,000-4,000字 = 6-12万字
- **长篇小说**：50+章，每章3,000-5,000字 = 15万字+

---

## 💡 黄金建议

1. **写作前**：大纲越详细，写作越快
2. **写作中**：每500字问自己"读者会继续看吗？"
3. **写作后**：朗读一遍，检查对话是否自然
4. **发布前**：用 `/check-quality` 最后检查一遍

---

## 🆘 紧急救援

**卡文了怎么办？**
```
/continue [已写内容] + "请提供3个可能的发展方向"
```

**写偏了怎么办？**
```
/check-quality [内容]
→ 查看问题 → 针对性修改
```

**不知道下一章写什么？**
```
回头看大纲的"伏笔时间表"
→ 找到该回收的伏笔
→ 围绕伏笔设计情节
```

---

## 📞 记住这三句话

1. **"读者停不下来"是唯一标准**
2. **具体的画面 > 抽象的描述**
3. **不要证明，只要创造**
