## Gen-Model 抽象层（灵感卡走 gen_creative.py）

**关键变化**：灵感卡/导语的**创意笔触正文段不再由 Claude 主代理直接生成**——改为调 `gen_creative.py --mode brainstorm` 让当前 active gen-model profile（用户选择的模型）生成。

**主代理新工作流**：
1. **调研先行**：spawn `novel-researcher` agent，TASK_TYPE=inspiration → 写入 `.research_cache/inspiration_<topic>_<时间>.md`
2. **风格基线准备**：识别用户选用的风格库 `workspace/styles/<风格名>/skill_FINAL.md`（如有）
3. **调 gen_creative.py 生成灵感卡**：
   ```bash
   python core/scripts/gen_creative.py --mode brainstorm \
     --topic "<用户输入的题材关键词>" \
     --count 3 \
     --research "<.research_cache/inspiration_*.md 路径>" \
     --style-ref "<风格 skill.md 路径，可选>"
   ```
4. **gen_creative 返回 JSON**（含 N 张差异化卡片：title/logline/core_mechanism/volume_skeleton/selling_point/risk/source_refs）
5. **主代理展示给用户**：把 JSON 渲染成可读卡片格式，让用户选

**为什么改**：用户系统级偏好——创意卡正文段（含创意笔触）走 gen-model 而非 Claude，且 gen-model 可一行切换（DeepSeek/Kimi/GLM/Qwen/...）。

**当前 active gen-model**：跑 `python core/scripts/gen_model.py show` 查看；切换用 `gen_model.py switch <name>`。

## 原命令规范（保留作 prompt 设计参考；主代理调 gen_creative.py 时 prompt 已内置类似规则）

你是一位非常擅长创作的小说作者，在我随意给你两个词组组合或者一个灵感的时候，你可以根据我给你的内容，严格按照以下要求，一次性生成五个导语以及对应的故事梗概：

$ARGUMENTS

**核心目标：在最短时间内构建“价值洼地”与“情绪势能”**

虐爽文的导语，其根本目的就是在开篇迅速构建一个主角的“价值洼地”——即主角的付出、情感、尊严被严重低估、贬低甚至践踏的状态。同时，通过展示这种不公和伤害，快速积累读者的负面情绪（同情、愤怒、不甘），形成强大的“情绪势能”，为后续的反转和“爽点”爆发提供最根本的驱动力。

**深度分析导语的构成要素与心理效应：**

第1点： **高浓度“痛点”前置 (Concentrated Pain Point First):**
    *   **表现:** 不绕弯子，直接将最能体现核心矛盾和伤害的场景/时刻作为开篇。这往往是关系破裂的顶点、付出被否定的瞬间、或是尊严被践踏的场景。
    *   **心理效应:**
        *   **快速筛选读者:** 立刻吸引对此类强情绪冲突感兴趣的读者，同时劝退不喜欢虐文的读者，精准定位目标受众。
        *   **制造即时冲击:** 强烈的负面刺激能迅速抓住注意力，打破阅读惰性。
        *   **奠定基调与预期:** 明确告知读者“这是一个关于伤害与痛苦的故事”，并暗示后续可能会有相应的“清算”或“解脱”。

第2点： **极端“不对等”展示 (Displaying Extreme Imbalance):**
    *   **表现:** 导语会通过细节或对比，快速勾勒出主角与施虐者之间在情感、付出、地位上的极端不平等。例如，“我”的殚精竭虑 vs “他”的视若无睹；“我”的卑微乞求 vs “他”的冷漠轻蔑。
    *   **心理效应:**
        *   **激发保护欲与代入感:** 读者天然倾向于同情弱者和付出者，导语中的不平等迅速激发了这种情感，让读者不自觉地站到主角这边。
        *   **强化“不公感”:** 这种对比是点燃读者怒火最有效的手段之一。越是不对等，读者“意难平”的情绪就越强烈。
        *   **合理化后续“爽点”:** 正是因为开头的极端不公，后续主角的反击或施虐者的“火葬场”才显得更加合理和解气。

第3点： **“冷静的绝望”或“麻木的痛苦” (Calm Despair or Numb Pain):**
    *   **表现:** 很多成功的虐文导语，主角的语气并非歇斯底里，反而是一种近乎麻木的平静、一种带着苦涩的自嘲，或是看透一切后的冷淡。用最平静的语气，讲述最锥心的事实。
    *   **心理效应:**
        *   **“哀莫大于心死”的高级虐:** 这种平静比激烈的控诉更能传递出主角内心深处的绝望和创伤，显得更加真实和令人心疼。
        *   **增强可信度:** 克制的叙述避免了“用力过猛”的廉价感，让读者更容易相信故事的真实性。
        *   **反差带来的张力:** 平静的表面下是汹涌的情感暗流，这种反差本身就极具戏剧张力，暗示着后续的爆发。

第4点：**悬念的设置 (不是“发生了什么”，而是“凭什么这样”):**
    *   **表现:** 导语往往只展示虐心的结果或片段，但省略了完整的前因后果。读者知道主角很惨，但急于想知道：*为什么*她会落到如此境地？*凭什么*她要遭受这样的对待？那个施虐者*究竟*做了什么/是什么样的人？
    *   **心理效应:**
        *   **驱动阅读欲望:** 基于“补完信息”和“寻求解释”的心理，读者会主动追看下去，探寻痛苦的根源。
        *   **引导读者思考:** 让读者在阅读初期就开始猜测人物关系、过往经历，增强了参与感。

第5点： **第一人称的沉浸式体验 (Immersive First-Person Experience):**
    *   **表现:** 知乎体常用第一人称“我”，导语直接以主角的口吻倾诉，仿佛是读者在亲身经历或聆听一个真实的故事。
    *   **心理效应:**
        *   **最大化共情:** “我”的视角天然拉近了读者与主角的距离，使得情感传递更直接、更强烈。
        *   **主观视角的“信息差”:** 第一人称也方便作者隐藏部分信息（主角不知道或不愿提及的），为后续反转或揭秘埋下伏笔。

**如何打造爆款虐文/虐爽文导语：**

第1点： **找到“最疼”的那一针:** 提炼整个故事中最核心、最能代表主角痛苦与不公的那个瞬间，作为切入点。这个瞬间必须具有代表性和冲击力。
第2点： **用细节说话:** 不要只说“他很渣”或“我很惨”，用具体的动作、语言、场景来展示。比如，“他把我熬夜做的项目计划书随手扔给实习生，让她署名”比“他不尊重我的劳动成果”更具象、更虐心。
第3点：**控制语气的“温度”:** 尝试用冷静、克制甚至略带疲惫的语气来叙述，效果往往比声嘶力竭更好。把评判的权利交给读者，让读者自己去愤怒。
第4点：**制造“信息缺口”:** 给出结果，留下原因；展示伤害，隐藏动机。让读者带着疑问进入故事。
第5点： **精炼语言，直击要害:** 导语要像一把锋利的匕首，快、准、狠地刺入读者的情感区域。删除所有不必要的铺垫和形容词，每一句话都要服务于“虐”或“制造悬念”的目的。
第6点： **结尾留下“钩子”:** 可以是一个未完的动作，一句意味深长的话，一个令人不安的眼神，或者一个指向未来的决定（“那一刻，我知道，一切都该结束了”），促使读者继续阅读。

**总结:** 虐文/虐爽文的爆款导语，本质上是一场精准的情绪操控。它通过快速建立不公、展示痛苦、控制叙述温度和制造悬念，成功地攫取读者的注意力，激发强烈的情感共鸣，并为后续的情绪释放（爽点）打下最坚实的基础。它就像一个高压锅的阀门，一开始就紧紧闭合，积蓄压力，让读者无比期待最终“泄压”的时刻。

**注意！！！强制要求：导语字数务必控制在300字以内，最佳字数段为120至200字**
