# 角色反应引擎

## 设计哲学

融合三大游戏的核心机制：
- **BG3 Approval**：主角的每个行为，所有在场角色都有态度反应
- **Hades 渐进揭露**：关系深度随互动次数逐步解锁
- **太吾绘卷 处世立场**：角色的价值观决定对事件的态度

## 一、处世立场系统（太吾绘卷）

每个角色有一个核心"处世立场"，决定TA对各类事件的本能态度：

```json
{
  "stance": {
    "type": "刚正/仁善/中庸/叛逆/唯我/务实",
    "values_priority": ["正义 > 情感 > 利益"],
    "approve_actions": ["惩恶扬善", "遵守规则", "保护弱者"],
    "disapprove_actions": ["欺骗", "背叛", "为达目的不择手段"],
    "neutral_actions": ["权宜之计", "善意的谎言"]
  }
}
```

### 立场类型

| 立场 | 核心价值 | 认可的行为 | 反感的行为 |
|------|----------|-----------|-----------|
| 刚正 | 规则、正义 | 惩恶、守诺、公正 | 欺骗、妥协、徇私 |
| 仁善 | 慈悲、宽容 | 帮助弱者、宽恕、牺牲 | 残忍、冷漠、报复 |
| 中庸 | 平衡、和谐 | 调解、妥协、顾全大局 | 极端、冒险、破坏秩序 |
| 叛逆 | 自由、反抗 | 挑战权威、打破规则、独立 | 服从、盲从、压迫 |
| 唯我 | 自利、生存 | 自保、精明、利益最大化 | 无谓牺牲、感情用事 |
| 务实 | 效率、结果 | 有效手段、理性决策 | 空谈、犹豫、道德洁癖 |

## 二、行为反应系统（BG3 Approval）

### 核心机制

主角（或任何角色）做出一个"有态度倾向"的行为时，**所有在场角色**根据自己的处世立场产生态度反应：

```
主角行为：当众揭穿王经理的谎言

在场角色反应：
  小张（仁善）：Approves +5（佩服勇气，但担心后果）
  老员工A（中庸）：Disapproves -3（破坏和谐，太冲动）
  上级（务实）：Neutral 0（观察局势，不表态）
  王经理（唯我）：Strongly Disapproves -15（被公开羞辱）
```

### 反应强度

| 强度 | 数值变化 | 触发条件 |
|------|----------|----------|
| Strongly Approves | +10~+20 | 行为完美契合角色核心价值 |
| Approves | +3~+8 | 行为符合角色立场 |
| Neutral | 0 | 行为与角色立场无关 |
| Disapproves | -3~-8 | 行为违背角色立场 |
| Strongly Disapproves | -10~-20 | 行为严重冒犯角色核心价值 |

### 反应不仅是数值

除了关系数值变化，角色还会有**行为反应**（用于写作）：

```json
{
  "reaction": {
    "character": "小张",
    "approval": +5,
    "visible_reaction": "眼睛亮了一下，嘴角微微上扬",
    "inner_thought": "这个人...比我勇敢多了",
    "behavioral_change": "之后会更主动接近主角",
    "dialogue_unlock": "下次私下见面时会说'那天你真帅'"
  }
}
```

## 三、渐进式揭露系统（Hades）

### 核心机制

角色之间的关系有"深度等级"，随着互动次数和关系数值逐步解锁更深层的内容：

```json
{
  "relationship_depth": {
    "level": 3,
    "max_level": 7,
    "interactions_count": 12,
    "unlock_history": [
      {"level": 1, "unlocked_at_ch": 1, "content": "表面寒暄，公事公办"},
      {"level": 2, "unlocked_at_ch": 3, "content": "开始有私人话题，偶尔开玩笑"},
      {"level": 3, "unlocked_at_ch": 6, "content": "分享个人经历，展现脆弱面"}
    ],
    "next_unlock": {
      "level": 4,
      "requirement": "trust > 60 且 interactions > 15",
      "content": "透露秘密/寻求帮助/展现真实面",
      "trigger_event": "某个危机时刻的共同经历"
    }
  }
}
```

### 深度等级定义

| 等级 | 关系状态 | 解锁内容 | 要求 |
|------|----------|----------|------|
| 1 | 陌生人 | 表面礼貌，公式化对话 | 初始 |
| 2 | 熟人 | 有私人话题，偶尔幽默 | 3次互动 |
| 3 | 朋友 | 分享经历，展现脆弱 | trust>30, 8次互动 |
| 4 | 密友 | 透露秘密，寻求帮助 | trust>60, 15次互动 |
| 5 | 知己 | 完全坦诚，无保留 | trust>80, 20次互动 |
| 6 | 灵魂伴侣/宿敌 | 深层羁绊，命运交织 | 特殊事件触发 |
| 7 | 超越 | 为对方改变自己的核心 | 全书高潮 |

### 渐进揭露的写作效果

- Level 1-2：对话简短、客套、信息量少
- Level 3-4：对话变长、有情感、开始透露背景
- Level 5-6：深度对话、内心独白、关键信息揭露
- Level 7：角色弧线的高潮——为对方做出改变

## 写作集成

### save-state 写后

每章结束后：
1. 扫描本章中所有"有态度倾向"的行为
2. 对每个行为，计算所有在场角色的反应（基于处世立场）
3. 更新关系数值
4. 检查是否有关系深度升级（解锁新等级）
5. 记录角色的可见反应（供下一章使用）

### write-chapter 写前注入

```
🎯 角色反应提示（本章关键行为的预期反应）：

本章预计行为：主角决定[行为描述]

各角色预期反应（基于处世立场）：
  【小张·仁善】→ Approves（会表现为：...）
  【王经理·唯我】→ Disapproves（会表现为：...）
  【上级·务实】→ Neutral（会表现为：...）

关系深度提示：
  主角↔小张：Level 3（可以有私人话题）
  主角↔王经理：Level 2（仍然公事公办）
  → 对话深度必须匹配关系等级，不能越级
```

### 与其他系统联动

- **态度着色系统**：处世立场是态度着色的"底色"
- **关系系统**：反应引擎驱动关系数值变化
- **人格深度**：渐进揭露决定角色何时"卸下面具"
- **群戏引擎**：多人场景中，每个人的反应基于各自立场
- **叙事导演**：关系深度升级是重要的叙事节点

## 操作

- `/reaction 模拟 [行为描述]` — 模拟一个行为，预览所有角色的反应
- `/reaction 查看 [角色A] [角色B]` — 查看两人的关系深度和互动历史
- `/reaction 立场` — 显示所有角色的处世立场
