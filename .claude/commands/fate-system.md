# 天道大势系统

## 核心哲学（洪荒流）

> 大势已定，小势可改。
> 天道划定了终点，但通往终点的路有千万条。
> 圣人不可逆天道大势，但可以在小势中布局，让结果对自己有利。

### 映射到小说写作

| 概念 | 洪荒原义 | 小说写作映射 |
|------|----------|-------------|
| 天道 | 宇宙底层规则 | 大纲/故事核心主题 |
| 量劫 | 天道的自我修复 | 每卷的核心冲突 |
| 大势 | 量劫的必然结果 | 每卷的确定结局（不可改） |
| 小势 | 达成大势的具体路径 | 每章的走向（用户可选） |
| 圣人布局 | 在小势中争取最优解 | 用户通过卡片选择路径 |
| 因果 | 行为的必然后果 | 选择的长期影响 |
| 气运 | 命运的倾向性 | 角色的"运势"影响事件概率 |

## 一、大势系统（卷级·不可改）

### 定义

大势 = 每卷的**核心结局**，在大纲阶段就已确定，用户不可改变。

```json
{
  "grand_fate": {
    "volumes": [
      {
        "volume": 1,
        "title": "青云入门",
        "chapters": [1, 10],
        "fixed_outcome": "主角离开青云宗",
        "fixed_events": [
          "主角必须经历宗门大比",
          "师父的秘密必须被揭露",
          "主角与王经理的冲突必须爆发"
        ],
        "theme": "成长与背叛",
        "emotional_destination": "从信任到幻灭"
      },
      {
        "volume": 2,
        "title": "独行天下",
        "chapters": [11, 20],
        "fixed_outcome": "主角建立自己的势力",
        "fixed_events": [
          "主角必须遇到命中贵人",
          "旧敌必须再次出现",
          "主角必须做出一个改变命运的选择"
        ],
        "theme": "独立与崛起",
        "emotional_destination": "从迷茫到坚定"
      }
    ]
  }
}
```

### 大势卡片（卷初展示）

每卷开始时，向用户展示本卷的"天道大势"——让用户知道终点在哪，但不知道怎么到达：

```
⚡ 天道大势 — 第一卷「青云入门」

本卷命定结局：主角将离开青云宗
不可改变的事件：
  · 宗门大比必须发生
  · 师父的秘密必须揭露
  · 与王经理的冲突必须爆发

但是——怎么到达这个结局，由你决定。
主角是被逐出的？主动离开的？还是被迫逃离的？
每一章的选择，都在塑造通往终点的路径。
```

### 大势不可逆规则

- 用户的章级选择**不能**改变卷级结局
- 如果用户的选择导向了与大势矛盾的方向，叙事导演会通过事件"纠正"回来
- 纠正方式要自然（不是强行转折），而是通过因果链让结果回到大势轨道

## 二、小势系统（章级·可选择）

### 定义

小势 = 每章的**具体走向**，由用户通过剧情走向卡片选择。

### 小势卡片生成规则（升级版）

小势卡片的生成必须满足以下约束：

1. **所有选项最终都通向大势**（不同路径，同一终点）
2. **选项之间的差异是"路径"而非"结局"**
3. **基于记忆生成**（过往选择影响当前可用选项）
4. **因果律**：之前的选择会缩小/扩大当前的选项池

```
📋 小势选择 — 第5章

天道大势提醒：本卷结局「主角离开青云宗」不可改变
当前距离大势：还有5章到达终点

┌─────────────────────────────────────┐
│ [A] 王经理在宗门大比前夜找到主角    │
│     "我知道你的秘密。明天的比试..."  │
│     → 路径：被动应对，提前暴露       │
│     → 因果：王经理获得主动权         │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ [B] 主角在藏经阁发现师父留下的信    │
│     信中揭示了一个惊人的真相...      │
│     → 路径：主动探索，掌握信息差     │
│     → 因果：主角获得谈判筹码         │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐
│ [C] 一个陌生人出现在宗门门口        │
│     他说认识主角的父亲...            │
│     → 路径：外部力量介入，局势突变   │
│     → 因果：引入新势力，格局扩大     │
└─────────────────────────────────────┘

无论选哪个，主角最终都会离开青云宗——
但选A是被逼走的，选B是主动走的，选C是被卷入更大漩涡而走的。
```

### 因果累积

用户的每次选择都会产生"因果"，影响后续选项：

```json
{
  "karma_ledger": {
    "choices_made": [
      {"ch": 3, "choice": "A", "karma": "王经理获得主动权", "long_term_effect": "第7章王经理会利用这个优势"},
      {"ch": 5, "choice": "B", "karma": "主角掌握信息差", "long_term_effect": "第8章可以用这个信息反击"}
    ],
    "accumulated_karma": {
      "主角vs王经理": "主角略占上风（信息差优势）",
      "主角vs宗门": "关系紧张（多次违规）",
      "主角vs外部势力": "未知（尚未接触）"
    },
    "locked_paths": ["因为第3章选了A，第8章的'和平解决'选项不再可用"],
    "unlocked_paths": ["因为第5章选了B，第9章多了一个'揭露真相'选项"]
  }
}
```

## 三、气运系统（隐性影响）

### 定义

气运 = 角色的"命运倾向性"，影响事件发生的概率和结果的好坏。

```json
{
  "fortune": {
    "主角": {
      "current_fortune": 65,
      "trend": "上升",
      "factors": [
        {"source": "师父遗泽", "value": +20, "duration": "永久"},
        {"source": "得罪王经理", "value": -10, "duration": "直到和解"},
        {"source": "发现秘密", "value": +15, "duration": "直到使用"}
      ]
    }
  }
}
```

### 气运对写作的影响

- 气运高时：偶遇更多是好事，危机中更容易化险为夷
- 气运低时：小事也可能出问题，需要更多努力才能成功
- 气运不直接决定结果，但影响"事情顺不顺利"的程度

## 写作集成

### outline 初始化

生成大纲时，必须明确每卷的"大势"：
- 每卷的确定结局
- 每卷的必须发生事件
- 每卷的主题和情感终点

### write-chapter 写前

注入当前的大势/小势状态：
```
⚡ 大势状态：
  本卷结局：[不可改]
  距离终点：还有X章
  必须事件剩余：[列表]

🎯 小势状态：
  用户上一次选择：[选项及因果]
  累积因果：[对当前章的影响]
  已锁定路径：[不再可用的选项]
  已解锁路径：[新增的选项]
```

### save-state 写后

更新因果账本：
- 本章的选择产生了什么因果？
- 哪些未来路径被锁定/解锁？
- 气运值是否变化？
- 距离大势终点还有多远？

---

## 操作

- `/fate 大势` — 显示当前卷的天道大势
- `/fate 因果` — 显示因果累积账本
- `/fate 气运 [角色]` — 查看角色气运值
- `/fate 路径` — 显示当前已锁定/已解锁的路径

**目标：让用户感受到"命运的重量"——终点已定，但路途由你选择。每个选择都有代价，每个代价都有回响。**
