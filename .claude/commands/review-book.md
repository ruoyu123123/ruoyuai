# 全书复盘

## 复盘维度

### 1. 角色弧线完整性
- 每个主要角色的 growth_arc 是否完整？
- 是否有角色"虎头蛇尾"（前期重要后期消失）？
- 角色的最终状态是否与大纲预期一致？

### 2. 伏笔回收率
- 总伏笔数 / 已回收数 / 未回收数
- 未回收的伏笔是否是有意留白（续集伏笔）还是遗漏？
- 契诃夫之枪是否全部"开火"？

### 3. 情绪曲线
- 绘制全书情绪值曲线
- 是否有"平淡区"（连续3章以上情绪值在3-5之间）？
- 大爽点是否在正确位置（30%/60%/90%）？

### 4. 风格一致性
- 前5章 vs 后5章的风格是否漂移？
- 角色声音是否保持一致？
- 是否有"AI腔"泄露？

### 5. 世界观一致性
- 是否有设定矛盾？
- 地图/时间线是否自洽？
- 势力关系是否合理？

### 6. 大势完成度
- 每卷的大势是否都达成？
- 用户的小势选择是否形成了连贯的故事线？
- 因果链是否自洽？

### 7. 数据统计
- 总字数 / 章节数 / 平均每章字数
- 角色数量 / 地点数量 / 物品数量
- 写作经验积累数 / 用户偏好数
