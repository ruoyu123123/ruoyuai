# 人格深度系统

## 设计哲学

> 人是复杂的。表面一套，背后一套。对不同人展现不同面。自己都不完全了解自己。

借鉴：
- CK3 的 Secrets/Hooks 系统（秘密→把柄→胁迫）
- "Toward Characters Who Observe, Tell, Misremember, and Lie"（AAAI 2015）
- Orbital Arcade 的 Lying NPCs 设计

## 写作集成

### write-chapter 写前注入

当角色出场时，注入其"当前面具"而非完整人格：

```
🎭 角色深度提示（内部参考，不直接展示给读者）：

【王经理】本章面具：
  对主角展现：不屑一顾、公事公办
  实际内心：感到威胁、在评估主角的实力
  本章可能的"破绽"：紧张时转笔频率加快

【前台小张】本章面具：
  对所有人展现：热情开朗、八卦
  实际内心：在暗中观察、收集信息
  本章可能的"破绽"：问问题时眼神会变认真
```

### 读者视角管理

**关键原则：** 读者看到的信息量 ≠ 角色知道的信息量 ≠ 角色的真实状态

```
信息层级：
  Level 1（读者看到的）：角色的外在行为和对话
  Level 2（读者能推断的）：通过"破绽"暗示的真实意图
  Level 3（读者不知道的）：角色的秘密和真实动机（后续揭露时产生反转）
```

写作时：
- 主角视角：只能看到 Level 1 + 偶尔察觉 Level 2
- 读者视角：看到 Level 1 + Level 2 的暗示（比主角多一点）
- 全知视角（如有）：偶尔展示 Level 3（制造悬念）

### save-state 写后更新

每章结束后检查：
1. 是否有角色的秘密被部分暴露？→ 更新 status
2. 是否有新的把柄产生？→ 追加到 hooks
3. 角色的面具是否出现了裂痕？→ 记录"破绽暴露"事件
4. 是否有角色的认知偏差被挑战？→ 可能触发性格转变

### 与其他系统的联动

- **关系系统**：信任度影响角色是否展示真实面（trust > 70 时可能卸下面具）
- **事件触发器**：秘密暴露是重大事件，自动触发连锁反应
- **伏笔系统**：角色的"破绽"是天然的伏笔（读者注意到了，等待揭露）
- **叙事导演**：秘密暴露的时机由导演控制（在最有戏剧性的时刻揭露）

## 认知框架系统（每个角色的主观世界模型）

### 设计哲学

> 每个人看到的世界都不一样。同一件事，不同人有不同的理解。
> 这不是"谁对谁错"，而是每个人的认知都受限于自己的经历、环境和视角。

借鉴：
- "Toward Characters Who Observe, Tell, Misremember, and Lie"（AAAI 2015）——角色有主观世界模型
- "NPC Knowledge in Persistent MMOs"——每个NPC维护独立的知识状态
- 心理学"Theory of Mind"——理解他人有不同于自己的信念和认知

### 认知框架数据结构

每个角色的人物卡增加 `cognition` 字段：

```json
{
```

### 认知差异如何影响写作

#### 1. 同一事件，不同角色的不同理解

```
客观事实：主角在会议上提出了一个新方案

王经理的认知：「他在挑战我的权威，想在上级面前表现」
前台小张的认知：「哇，新人好勇敢，我都不敢在会上发言」
上级的认知：「有意思，这个新人有想法，可以利用」
主角自己的认知：「我只是想解决问题而已」
```

#### 2. 认知差异驱动冲突

大部分冲突不是因为"坏人做坏事"，而是因为**认知差异**：
- A 认为 B 在针对自己 → A 反击 → B 认为 A 无理取闹 → 冲突升级
- 双方都认为自己是对的，因为他们看到的"事实"不同

#### 3. 认知更新（角色成长的本质）

角色成长 = 认知框架的更新：
- 发现自己的 `believes_true` 其实是错的 → 世界观动摇
- `perception_filters` 被打破 → 开始看到之前忽略的东西
- `confirmation_bias` 被挑战 → 开始接受不同的证据

### 写作集成

#### write-chapter 写前注入

```
🧠 认知差异提示（本章出场角色的主观视角）：

【王经理】看到的世界：
  认为主角是：来抢位置的威胁
  解读方式：主角的任何行为都被解读为"有野心"
  本章可能的误判：把主角的善意理解为"收买人心"

【前台小张】看到的世界：
  认为主角是：有趣的新人
  解读方式：倾向于正面解读主角的行为
  本章可能的误判：忽略主角身上的危险信号

→ 写作时：每个角色的反应必须基于TA自己的认知，而非客观事实
→ 禁止：让角色做出超越其认知框架的判断（除非有新信息输入）
```

#### save-state 写后更新

每章结束后检查：
1. 是否有角色接收到了挑战其认知的新信息？
2. 该角色的 `information_processing.update_speed` 是快还是慢？
3. 如果是"快"→ 立即更新 `subjective_reality`
4. 如果是"慢"→ 记录为"待消化的信息"，需要多章才能改变认知
5. 是否有角色的 `distorted_memories` 被纠正？→ 可能触发情感爆发

### 与其他系统的联动

- **关系系统**：认知差异是关系冲突的根源（"我以为你在害我"）
- **事件触发器**：当角色的 `believes_true` 被证伪时，触发认知危机事件
- **叙事导演**：认知翻转（发现真相）是最有力的剧情高潮
- **伏笔系统**：角色的错误认知本身就是伏笔（读者知道真相，等待角色发现）
- **群戏引擎**：多人场景中，每个人基于自己的认知做出不同反应

## 态度着色系统（同一事实，不同人的不同"颜色"）

### 设计哲学

> 认知是"看到什么"，态度是"怎么感受"。
> 同一件事，每个人的感受完全不同——不是因为他们看到的不同，而是因为他们的情感、立场、利益、经历给事实"上了不同的颜色"。

这不是 bug，这是人性的核心特征。

### 态度着色的 7 种来源

### 态度着色如何影响写作

#### 示例：主角在会议上提出了一个好方案

```
客观事实：方案确实有创意，解决了一个实际问题

王经理（情感滤镜=厌恶 + 利益冲突=竞争）：
  着色后的感受：「又在出风头。这种方案谁都能想到，不过是运气好。」
  行为：冷淡回应，找茬挑毛病

小张（情感滤镜=好感 + 无利益冲突）：
  着色后的感受：「好厉害！新人就能想到这种方案，太有才了。」
  行为：会后偷偷竖大拇指

上级（无情感滤镜 + 利益=可利用）：
  着色后的感受：「有意思。这个人可以为我所用。」
  行为：不动声色，但记住了这个人

老员工A（群体认同=外人 + 情绪=焦虑）：
  着色后的感受：「新人来了就想改规矩？我们这么多年的经验算什么？」
  行为：私下抱怨，拉帮结派
```

#### 关键写作规则

1. **禁止"客观旁白"**：不要写"王经理虽然表面冷淡，但内心其实认可了这个方案"——如果他的情感滤镜是厌恶+利益冲突，他**真的**觉得这个方案不好，不是"嘴硬心软"
2. **态度着色是真实的**：角色不是"明知道好但故意说不好"，而是**真心觉得不好**——因为他的情感/立场/利益让他看到的就是"不好"
3. **只有经历重大事件后才会改变着色**：不是"想通了就好了"，而是需要足够强的冲击才能打破固有的着色模式
4. **读者可以看到着色的不合理**：通过对比不同角色的反应，读者能感受到"这个人的判断被情感扭曲了"——但角色自己不知道

### write-chapter 写前注入

```
🎨 态度着色提示（本章关键事件的不同角色感受）：

本章核心事件：[事件描述]

各角色的"着色"反应：
  【王经理】情感滤镜(厌恶) + 利益(竞争) → 感受：威胁/不屑
  【小张】情感滤镜(好感) + 无利益冲突 → 感受：佩服/开心
  【上级】无情感 + 利益(可利用) → 感受：冷静评估

→ 写作时：每个角色的反应必须符合TA的着色模式
→ 禁止：让有利益冲突的角色"客观公正地"评价对手
→ 禁止：让讨厌某人的角色突然觉得对方"其实挺好的"（除非有重大事件触发）
```

### save-state 写后更新

每章结束后检查：
1. 是否有事件改变了角色的情感滤镜？（如：讨厌的人救了自己→滤镜动摇）
2. 是否有利益关系变化？（如：不再是竞争对手→利益扭曲消失）
3. 是否有情绪状态变化？（如：大喜→大悲→判断力下降）
4. 是否有创伤被触发？（如：某个场景让角色想起过去→投射反应）
5. 如有变化，更新 `attitude_coloring` 对应字段

### 与认知框架的区别

| | 认知框架 | 态度着色 |
|---|---|---|
| 关注点 | 角色"看到"什么 | 角色"感受"什么 |
| 来源 | 信息+经验+逻辑 | 情感+立场+利益+经历 |
| 可控性 | 可以通过新信息改变 | 很难通过理性改变 |
| 自我意识 | 角色可能意识到自己的认知有限 | 角色通常不知道自己被"着色"了 |
| 示例 | "我不知道他是穿越者" | "我就是看他不顺眼，说不出为什么" |

**目标：让角色的反应不是"理性分析后的结论"，而是"被情感/立场/利益着色后的本能反应"——这才是真实的人**

**目标：让每个角色都是"冰山"——读者看到的只是水面上的10%，水面下的90%驱动着真实行为。当冰山翻转时，就是最震撼的反转。**
