# 地图系统

## 功能

### 查看地图
- 展示当前世界的所有已知地点及其连接关系
- 显示各角色当前所在位置
- 标注已解锁/未解锁区域

### 地图数据结构

`_数据库/地图.json` 格式：

```json
{
  "locations": [
    {
      "id": "青云宗",
      "name": "青云宗",
      "type": "宗门/城市/野外/秘境/其他",
      "description": "坐落于青云山巅的修仙大宗",
      "sub_locations": ["藏经阁", "练功房", "宗主殿", "外门广场"],
      "connections": [
        {"to": "青云镇", "distance": "半日路程", "method": "步行/飞行"},
        {"to": "万妖山", "distance": "三日路程", "method": "步行"}
      ],
      "discovered_at_ch": 1,
      "atmosphere": "庄严肃穆，灵气充沛",
      "events_here": ["第1章入门考核", "第5章宗门大比"]
    }
  ],
  "character_positions": {
    "主角": {"location": "青云宗·藏经阁", "since_cluster": 5},
    "王经理": {"location": "青云镇·客栈", "since_cluster": 4}
  },
  "travel_log": [
    {"ch": 3, "character": "主角", "from": "青云镇", "to": "青云宗", "method": "步行"}
  ]
}
```

### 地图操作

1. **添加地点**：`/map 添加 [地点名] [类型] [描述]`
2. **移动角色**：`/map 移动 [角色] [目的地]`（自动记录到 travel_log）
3. **查看位置**：`/map 谁在哪`
4. **查看连接**：`/map [地点名] 能去哪`
5. **全览**：`/map 全图`

### 写作集成

- 每章写前，从地图中获取当前场景的 atmosphere 和 sub_locations
- 角色移动时自动检查距离是否合理（不能瞬移）
- 新地点出现时自动追加到地图
- save-state 中自动更新角色位置

### 地图可视化（文本版）

```
[青云宗] ←半日→ [青云镇] ←一日→ [万妖山]
    ↑                              ↓
  飞行(1时辰)                   [深渊]
    ↓
[天机阁]
```
