# 契诃夫之枪引擎（CFPG）

## 设计哲学

> "如果第一幕墙上挂了一把枪，第三幕它必须开火。" — 契诃夫

传统伏笔管理是被动的（人工标注）。本引擎是主动的：
- **自动检测**：正文中出现的重要物件/细节/暗示，自动标记为"潜在伏笔"
- **强制回收**：标记的伏笔必须在指定章节前回收，否则报警
- **连锁反应**：一个伏笔的回收可以触发新的伏笔

## 伏笔分类

| 类型 | 说明 | 回收期限 | 示例 |
|------|------|----------|------|
| 🔫 契诃夫之枪 | 正文中特意描写的物件 | 3-5章内必须回收 | "桌上那把生锈的匕首" |
| 🌱 种子 | 看似无关的细节，后续会长成大树 | 5-10章 | "他无意中提到的一个名字" |
| 💣 定时炸弹 | 读者知道但角色不知道的危险 | 1-3章内爆发 | "信封里的照片" |
| 🔮 预言 | 明确的预示/暗示 | 全书范围 | "老人说的那句话" |
| 🪞 镜像 | 前后呼应的场景/对话 | 灵活 | "开头和结尾的同一个动作" |

## 自动检测规则

save-state 执行时，扫描本章正文，自动标记以下为"潜在伏笔"：

1. **特写描写的物件**：如果某个物件被用超过 2 句话描写，标记为 🔫
2. **角色的异常行为**：如果某角色做了与性格不符的事，标记为 🌱
3. **未解释的现象**：如果出现了没有解释的异常事件，标记为 💣
4. **角色的预言/警告**：如果某角色说了预示性的话，标记为 🔮
5. **重复出现的意象**：如果某个意象/物件第二次出现，标记为 🪞

## 副线追踪系统（v16 新增 · 移植自编剧软件subplot tracking）

**核心：伏笔不再是散点——按"副线"分组，追踪每条线的独立进度。**

在 `_数据库/伏笔表.json` 新增 `subplots` 字段：

```json
{
  "subplots": [
    {
      "id": "sp_father",
      "name": "父亲失踪线",
      "status": "active",
      "started_ch": 1,
      "related_promises": ["fs_001", "fs_007", "fs_015"],
      "related_secrets": ["sc_003"],
      "progress_pct": 35,
      "last_advanced_ch": 3,
      "description": "许遥追查父亲20年前失踪的真相"
    },
    {
      "id": "sp_romance",
      "name": "秦玥感情线",
      "status": "dormant",
      "started_ch": 9,
      "related_promises": ["fs_010"],
      "progress_pct": 10,
      "last_advanced_ch": 10,
      "description": "许遥与秦玥从相遇到信任"
    }
  ]
}
```

**副线规则：**
- 每条副线关联多个伏笔（promises/secrets/deadlines）
- save_state时自动计算progress_pct = 已回收伏笔数/总关联伏笔数
- 连续5章未推进的副线→audit_consistency标记为"dormant冷冻"
- 连续10章未推进→标记为"abandoned遗弃"（可能是bug）
- build_manifest注入时，优先提醒"即将遗弃"的副线

**与伏笔的关系：**
- 伏笔是散点（单个约定）
- 副线是线（一组相关伏笔形成的叙事线索）
- 副线追踪解决"写着写着忘了某条线"的问题

## 回收方式

| 方式 | 说明 |
|------|------|
| 直接回收 | 伏笔直接兑现（枪开火了） |
| 反转回收 | 伏笔以意想不到的方式兑现 |
| 升级回收 | 伏笔的意义比预期更大 |
| 连锁回收 | 回收一个伏笔的同时埋下新伏笔 |

## 写作集成

- **write-chapter 写前**：注入即将到期的伏笔，标注"本章必须回收"
- **save-state 写后**：自动扫描新伏笔 + 检查回收情况
- **check-quality**：检查是否有超期未回收的伏笔（扣分）

## 操作

- `/foreshadowing 查看` — 显示所有伏笔状态
- `/foreshadowing 到期` — 显示即将到期的伏笔
- `/foreshadowing 添加 [类型] [描述] [到期章节]` — 手动添加
- `/foreshadowing 回收 [id]` — 标记某伏笔已回收
