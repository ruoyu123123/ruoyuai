# 势力与成长系统

## 设计哲学

借鉴鬼谷八荒/修仙游戏的核心系统：
- 角色有"实力等级"，影响能做什么、不能做什么
- 势力/阵营有层级，角色在其中有地位
- 实力差距决定冲突的可能结果

## 实力等级体系（可自定义）

默认修仙体系：
```
炼气(1-3) → 筑基(4-6) → 金丹(7-9) → 元婴(10-12) → 化神(13-15)
```

现代都市体系：
```
普通人(1) → 新人(2-3) → 骨干(4-6) → 精英(7-9) → 高管(10-12) → 大佬(13-15)
```

## 实力对剧情的影响

- **实力差 > 3级**：弱者无法正面对抗强者（必须用计谋/外力）
- **实力差 1-2级**：可以对抗但处于劣势
- **实力相当**：正面冲突结果不确定
- **突破时刻**：实力提升是重要的剧情节点（爽点）

## 写作集成

- **write-chapter 写前**：注入角色当前实力等级，确保战斗描写符合实力设定
- **save-state 写后**：如有实力变化（突破/受伤/获得新能力），更新 power_level
- **事件触发器**：实力达到某级别时触发特定事件（如"金丹期才能进入秘境"）
- **关系系统联动**：势力地位影响 NPC 对主角的态度

## 操作

- `/power 查看 [角色]` — 显示角色实力详情
- `/power 对比 [角色A] [角色B]` — 对比两人实力差距
- `/power 突破 [角色]` — 记录角色突破
- `/power 势力` — 显示所有势力关系图
