# 质量检查清单

## ✅ 核心指标

### 1. 开头是否足够劲爆？
- [ ] 前100字是否立刻抓住注意力？
- [ ] 是否痛点/冲突前置？
- [ ] 是否避免无意义铺垫？

### 2. 读者是否解气？
- [ ] 虐点是否足够密集？
- [ ] 爽点是否让人满足？
- [ ] 反转是否出人意料？

### 3. 主角状态是否形成有效"爽"点？
- [ ] 主角离开施虐环境后的状态？（更好/平静）
- [ ] 是否展现精神境界的提升？
- [ ] 是否避免单纯的物质/地位碾压？

### 4. 人物行为逻辑是否一致？
- [ ] 角色行为符合性格设定？
- [ ] 决策有合理动机？
- [ ] 信息差运用是否合理？

### 5. 节奏是否紧凑，重点突出？
- [ ] 无冗余情节？
- [ ] 高潮低谷分布合理？
- [ ] 每章都有明确的情节推进？

---

## ❌ 禁忌检查

### 旁白类禁忌
- [ ] 是否有"表面看起来...但实际上..."类表述？
- [ ] 是否有宏大空泛的概括性描述？
- [ ] 是否所有叙述都有具体依托？

### 对话类禁忌
- [ ] 对话是否口语化？
- [ ] 是否避免"从今天起""你已踏入"等非日常用语？
- [ ] 是否有人味和真实感？

### 环境描写禁忌
- [ ] 环境描写是否超过2-3句？
- [ ] 是否服务于情节而非单纯营造氛围？

### 心理活动禁忌
- [ ] 是否过度描写内心独白？
- [ ] 是否多用行动代替心理描写？

### 结尾禁忌
- [ ] 是否避免总结性结尾？
- [ ] 章节结尾是否用具体场景/动作收束？

---

## 📊 评分标准

**优秀（90-100分）**
- 所有核心指标全部达标
- 无任何禁忌违反
- 情节引人入胜，读者欲罢不能

**良好（75-89分）**
- 核心指标基本达标
- 偶有1-2处禁忌违反但不影响阅读
- 情节流畅，有亮点

**及格（60-74分）**
- 部分核心指标未达标
- 多处禁忌违反
- 情节平淡，需要改进

**不及格（60分以下）**
- 多数核心指标未达标
- 严重违反写作禁忌
- 建议重写

---

## 💡 改进建议格式

针对检查出的问题，请提供：

1. **问题定位**：具体章节/段落
2. **问题类型**：属于哪类禁忌或指标
3. **修改建议**：如何改进（给出对比示例）
4. **预期效果**：改进后的阅读体验提升

---

**检查目的：确保每一章都能让读者"停不下来"**
